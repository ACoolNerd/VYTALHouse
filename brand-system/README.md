# VYTAL House Official Brand System

**Status:** Official  
**Version:** 1.0.0  
**Official positioning line:** **Renew • Restore • Recharge**

This directory is the canonical identity control plane for VYTAL House. It governs every website, application, AI system, agent, location, equipment label, presentation, social profile, vendor file, and partner execution.

## Approved identity hierarchy
1. Primary stacked VYTAL House wordmark.
2. VH/house monogram.
3. Circular seal for formal or commemorative use.
4. App icon for digital products and profile images.
5. Approved horizontal, ultrawide, square, and story lockups.

## Critical rule
The former line **Recovery • Contouring • Longevity** is deprecated. Do not use it in new work without written brand-owner approval.

## Included repository assets
- Official flat-gold and white SVG production assets.
- JSON and CSS design tokens.
- Brand governance and repository synchronization rules.

The metallic-gold raster masters, complete social/export suite, web download library, and 18-page official brand book are maintained in the versioned VYTAL House Brand System release package. Metallic SVG gradients are not represented by the flat production SVGs in this directory.

## Implementation contract
- Preserve aspect ratio, clear space, and source-file integrity.
- Do not redraw, stretch, rotate, recolor, outline, or add effects.
- Use the supplied wordmark artwork; do not recreate it with typography.
- All downstream VYTAL repositories must consume this version instead of creating competing brand systems.
- Record the brand-system version in release notes when identity files or tokens change.

## Professional gap
Before large-format fabrication or formal trademark production, commission a true editable vector master from the approved geometry and complete trademark/licensing review with qualified counsel.
