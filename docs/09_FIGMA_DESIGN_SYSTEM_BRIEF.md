# 09 - Figma Design System Brief

## Design Intent
VYTAL House should feel like a premium spacecraft lounge: dark atmospheric surfaces, crisp white typography, chrome and warm gold accents, controlled red therapy glow, and small cyan/green system highlights.

## Screens To Create
- Website home.
- Membership and services.
- Facility/floor plan.
- Member dashboard.
- Booking flow.
- Admin dashboard.
- Vendor CRM.
- Content calendar.

## Tokens
Use `importables/figma/vytal_tokens.json`.

## Live Figma Gate
Live Figma file creation is prepared but not executed until approved.
