# Brand Isolation & Naming Guidelines

VYTAL House is an isolated business entity. To maintain proper compliance, legal shielding, and clear partner positioning, all code, user-facing texts, marketing materials, and documents must follow strict branding guidelines.

## 1. Allowed Terms
Always use the correct brand terms:
- **Club Name**: `VYTAL House`
- **Tagline**: `Recharge. Recover. Evolve.`
- **Owners**: `Chauncey Gardner` and `Kathy Ha`
- **Location**: `6000 Merriweather Drive, Columbia, MD`

## 2. Forbidden Terms (Brand Isolation)
Under no circumstances should any of the following terms appear in user-facing code, API responses, CSS classes, copy, or product documentation:
- `ACool`
- `acool`
- `AION`
- `FREED`
- `Freed`
- `FREEDOM LAB`

The quality verification suite regularly scans all code artifacts for these terms. Any detection will cause the build pipeline to fail.
